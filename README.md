# Student Grading System  

A Python-based student grading system that manages student records, including IDs, personal details, and module grades. It supports adding, searching, sorting, and removing students, with final grades automatically calculated. Sorting is done via heapsort, and users can view detailed student information through a command-line interface.  

## Features  

- **Student Management**: Easily add, search, update, or remove student records.  
- **Automatic Grade Calculation**: Final grades are computed based on module scores.  
- **Sorting with Heapsort**: Student records are efficiently sorted using heapsort.  
- **Detailed Student Info**: View complete student details through a command-line interface.  

## Technologies Used  

- **Language**: Python  
- **Sorting Algorithm**: Heapsort  
- No external libraries are needed, as the project runs on core Python.
